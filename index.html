FERROWORKER

A 1m x 1m x 1m build size 3D printer that can be assembled in 5 days.

About Features Cost & BOM
01

About the Project

The FERROWORKER will be a 1m x 1m x 1m build size 3D printer that can be assembled in 5 days, with the target builder being 14. We will make a full guide to assembly.

02

Tool Changer

The project will have a tool changer built into one, featuring:

  • 3D Printer
  • Laser Cutter
  • CNC Drill
03

Cost & BOM

We will also be making it under 800 AUD in parts so it is affordable.
